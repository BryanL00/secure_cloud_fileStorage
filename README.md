# Secure Cloud File Storage System with RBAC
This project is a Final Year Project (FYP) that focuses on developing a secure cloud-based file storage system. The system integrates encryption techniques and Role-Based Access Control (RBAC) with resource tag to ensure that only authorized users can access stored files.

The application allows users to securely upload, store, and manage files in the cloud while maintaining data confidentiality and controlled access.

## Key Features
- Secure user authentication
- Role-Based Access Control (RBAC) with resource tag
- Encrypted file storage
- Secure file upload and download
- Access control based on user roles
